CAWINE TEMPLATE V2 COMPLETE

Isi template:
- HTML, CSS, dan JavaScript lokal saja.
- Tidak memakai framework.
- Teks utama, warna, link, produk, promo, gallery, FAQ, dan kontak berada di assets/js/config.js.
- Warna utama berada di assets/css/theme.css.
- Struktur CSS dipisah agar mudah di-maintenance.

Folder penting:
- index.html = struktur halaman utama.
- assets/js/config.js = ganti isi bisnis, teks, link, produk, dan gambar.
- assets/js/app.js = logika render, filter produk, FAQ, navigasi, dan WhatsApp.
- assets/css/theme.css = warna dan ukuran dasar.
- assets/css/base.css = reset dan aturan dasar.
- assets/css/layout.css = container, header, footer, dan grid utama.
- assets/css/components.css = tombol, badge, card dasar, dan animasi.
- assets/css/sections.css = tampilan tiap section.
- assets/css/responsive.css = tablet dan mobile.

Cara ganti bisnis:
1. Ganti teks dan data di assets/js/config.js.
2. Ganti warna di assets/css/theme.css.
3. Ganti gambar di assets/img lalu sesuaikan path di config.js.
4. Buka index.html dengan Live Server.

Catatan:
- Nomor WhatsApp di config.js harus format internasional tanpa tanda +.
- Jika gambar tidak tampil, cek path file dan ekstensi huruf besar/kecil.
